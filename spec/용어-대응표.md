# 용어 대응표 (eSync ↔ 우리 시스템)

[eSync-OTA-시스템사양서](eSync-OTA-시스템사양서.md) 본문은 eSync 용어를 쓴다. 여기서 우리 시스템 용어(DOC-00 기준)와의 대응을 정리한다.
표제어별 항목으로, 상호 참조는 `[[표제어]]`로 잇는다.

---

## eSync Server

- **우리 용어:** 배포 플랫폼 (자체 OTA Platform) — DOC-10 §2.2
- **뜻:** 캠페인·타겟팅, Component·Package DB, [[server signing]], 감사를 담당하는 클라우드 백엔드.
- **관련:** [[eSync Client]] · [[Operator UI]] · [[GPDM]]

## eSync Client

- **우리 용어:** TGU (인스톨러)
- **뜻:** 장비의 게이트웨이 노드. 클라우드와 통신하고 업데이트를 오케스트레이션한다. 이더넷↔CAN 브릿지.
- **관련:** [[eSync Agent]] · [[eSync Server]]

## eSync Agent

- **우리 용어:** 타겟 업데이트 에이전트
- **뜻:** server signature 검증·복호화·플래시를 수행하는 주체. Step 1에서는 [[eSync Client]]와 한 노드에 동거한다.
- **관련:** [[eSync Client]] · [[trust anchor]]

## server signing (서버 서명)

- **우리 용어:** 중앙집중 서명 / CS-IC (KMS 서명 서비스) — DOC-20 §1.2
- **뜻:** eSync Server가 Component·Package에 수행하는 유일 서명. 디바이스가 검증하는 대상이다. 서명 키는 [[HSM]]에 보관.
- **관련:** [[trust anchor]] · [[Signed Component Database]]

## trust anchor (신뢰앵커)

- **우리 용어:** 검증 앵커 — DOC-10 §1.4
- **뜻:** [[eSync Agent]]가 server signature를 검증하는 데 쓰는 eSync Server 서명 인증서.
- **관련:** [[server signing]]

## Component / Package / Campaign

- **우리 용어:** 컴포넌트 / 패키지 / 캠페인 (동일 개념)
- **뜻:** Component(ECU 대상 버전형 SW 요소) → Package(순서·의존·롤백 묶음) → Campaign(대상군 배포) 조립 구조.
- **관련:** [[GPDM]] · [[Signed Component Database]]

## Signed Component Database

- **우리 용어:** 서명된 컴포넌트 저장소
- **뜻:** eSync Server가 server signing을 마친 Component를 보관하는 저장소.
- **관련:** [[server signing]] · [[Component / Package / Campaign]]

## Operator UI

- **우리 용어:** OTA 운영 플랫폼 (PS) · 운영 콘솔
- **뜻:** 캠페인·패키지·설치현황을 운영하는 단일 프론트엔드. RBAC로 딜러·AS에 부분 개방한다. Product Service(AS) 부서가 운영.
- **관련:** [[eSync Server]]

## GPDM

- **우리 용어:** (신규 연동) HD현대건설기계 PLM
- **뜻:** SW와 SW BOM을 관리하는 PLM. eSync에서는 Component·SW BOM의 **소스 어댑터**이자 출처 원장. 유일 소스로 정책화.
- **관련:** [[eSync Server]] · [[Vehicle Identity Provider]]

## Vehicle Identity Provider

- **우리 용어:** VLM (차량 레지스트리) — DOC-10 §2.2
- **뜻:** 식별자↔VIN 매핑과 SBOM 이력을 담당하는 신원 서비스. 현재 개념적 추상(미도입).
- **관련:** [[GPDM]]

## PKI (adapter) / HSM

- **우리 용어:** KMS · CA 계층 (Root CA · Dev-IC · CS-IC) — DOC-10 §1
- **뜻:** 인증서 발급과 [[server signing]] 키 보관을 담당. 서명 키는 HSM/KMS 밖으로 나가지 않는다.
- **관련:** [[server signing]] · [[trust anchor]]

## ECU (자원제약)

- **우리 용어:** 비-HSM 제어기 (플래시 대상)
- **뜻:** 복호화·서명검증을 스스로 못 하는 제어기. Step 1에서 UDS on CAN으로 평문 플래시된다.
- **관련:** [[eSync Agent]]

## Air Interface / eSync Messaging Protocol

- **우리 용어:** 통신 계층
- **뜻:** eSync Server와 [[eSync Client]]가 주고받는 제어·메타데이터 채널. 전송(AWS IoT Core MQTT 등)은 교체 가능.
- **관련:** [[eSync Client]]
