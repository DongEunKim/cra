# spec — eSync 기반 업데이트 사양 문서 지도

건설기계 제어기의 OTA·유선 업데이트를 Excelfore eSync 위에 정의하는 사양 묶음이다.
문서는 **공통 계층**(모든 제어기에 적용)과 **제어기별 계층**(능력별 변주)으로 나뉜다.

## 구조

```
공통 계층 ─ 모든 제어기에 적용
  00 용어집            eSync ↔ 우리 시스템 용어 대응
  10 PKI               인증기관·인증서·신뢰체인·키 보관
  20 프로비저닝        키·인증서·신뢰앵커 주입, 클라우드 등록
  30 eSync OTA 공통     아키텍처·워크플로·서명·전송·타겟팅·정책·감사
  40 유선 업데이트     DMS·SGW·OBD-II 유선 경로(공통 인프라)

제어기별 계층 ─ 30 공통을 상속, 능력별 변주
  31 EPOS-10i          HSM 없음·TGU 대행 검증·평문·싱글뱅크·0x27
  32 EPOS-30i          HSM·자체 검증·암호화(Secure Flash)·A/B·0x29
  33 ECU(엔진 제어기)  HSM 유무 혼재·31/32 프로파일 분기·파워트레인개발팀·유선 3케이스
  (34…)                향후 제어기
```

## 읽는 순서

1. **처음이면** 00(용어) → 30(공통 아키텍처)로 전체 골격을 잡는다.
2. **PKI·키가 궁금하면** 10 → 20.
3. **특정 제어기 구현은** 30을 전제로 31(EPOS-10i)·32(EPOS-30i)·33(ECU).
4. **유선 정비 경로는** 40(+ 제어기별 변주).
