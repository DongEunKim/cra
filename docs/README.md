## 문서 작성 규약

- **번호 체계:** 폴더 접두 번호(00/10/20/30)로 문서 순서를 고정한다.
- **버전:** 각 문서 상단 메타 블록에 문서 버전·분류·개정 이력을 명시한다.
- **용어:** [00-공통/용어집.md](00-공통/용어집.md)에 정의된 표기를 따른다(약어 최초 등장 시 풀어쓰기).
- **다이어그램:** `assets/diagrams/`의 SVG를 상대경로로 참조한다.
- **상호참조:** 문서 간 참조는 문서 ID와 절 번호로 표기한다 (예: `DOC-20 §6`).

## 문서별 상태

각 문서 폴더의 `README.md`(또는 인덱스)에 현재 정제 진행 상태와 원본 매핑을 기록한다.
