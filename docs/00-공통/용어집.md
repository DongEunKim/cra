# 용어집 · 약어 · 참조표준 (DOC-00)

> 세 원본 문서에서 사용된 용어를 통합·정규화한다. 정제 과정에서 표기 흔들림을 방지하기 위한 기준 문서.

## 핵심 용어

| 용어 | 정의 |
|------|------|
| 배포 서명 (Distribution Signature) | 배포 서버(CS-IC)가 부착, 인스톨러(TGU)가 검증하는 외부(Outer) 서명 |
| 펌웨어 서명 (Firmware Signature) | SW 개발자/벤더가 부착, 타겟 제어기(HSM)가 검증하는 내부(Inner) 서명 |
| 이중 전자서명 (Dual Signature) | 배포 계층 + 설치 계층으로 분리된 2단 서명 구조 |
| SW-Group-Key | 펌웨어 암호화용 대칭키. 인증서 확장 필드에 랩핑되어 주입 |
| Secure Flash | 대칭키(Group-Key) 기반 펌웨어 기밀성 보호(암호화 배포) |
| Secure Boot | 부팅 시 활성 뱅크 무결성을 HSM으로 재검증하는 절차 |
| Anti-Rollback | HSM 비휘발성 카운터로 구버전 다운그레이드를 차단 |
| Chain of Trust | Root CA → 개발자 인증서 → 펌웨어 서명으로 이어지는 신뢰 연쇄 |
| 활성 뱅크 (Active Bank) | A/B 뱅크 중 현재 실행 중인 펌웨어 저장 구역 |
| Challenge-Response | UDS 0x29 난수 서명 기반 상호 인증 |

## 알고리즘 규격 (원본 pki_v1.2 기준)

| 항목 | 규격 |
|------|------|
| PKI/디바이스 서명 | ECC secp256r1 (NIST P-256) + SHA-256 |
| UDS Challenge | 16 Bytes (TRNG) |
| UDS Signature | 64 Bytes (ECDSA P-256, R‖S Raw) |
| 펌웨어 암호화 | AES-256-GCM (TSK) |

## 참조 표준 (초안 — 확정 필요)

- ISO 14229 (UDS), ISO 14229-1 §0x29 Authentication
- ISO 21434 (도로차량 사이버보안 엔지니어링)
- UNECE R155 / R156 (사이버보안 / SW 업데이트 관리)
- X.509 v3 (RFC 5280)
- EU Cyber Resilience Act (Regulation (EU) 2024/2847)
