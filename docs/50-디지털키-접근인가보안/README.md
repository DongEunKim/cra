# DOC-50 · 디지털키 접근·인가 보안 (A5)

**본문:** [디지털키-접근인가-보안명세서.md](디지털키-접근인가-보안명세서.md) (v0.1 스켈레톤)
**상태:** 🔴 신규·예정 (자리 예약 — 코어 안정화 후 착수)
**지배 표준:** CCC(Car Connectivity Consortium) Digital Key

장비의 물리 접근·조작 인가를 위한 **CCC 기반 디지털키** 보안. 현재 디지털키 시스템이 CRA에 부합하지 않아
CCC 적용 디지털키로 전환한다. **코어 PKI(DOC-10: FOTA·진단·클라우드)와는 별도 신뢰 도메인**이며 자체
암호 스위트를 쓴다.

## 핵심 구성 (요지)
- **TGU 내 BLE MCU** = 장비 측 디지털키 엔드포인트 (TGU의 세 번째 역할)
- **FMS** = 인증된 사용자 앱에 장비 디지털키를 **발급**하는 주체
- **모바일앱** = 사용자 디지털키 보유·장비와 보안 통신

## 미결 / 착수 시 확정
- [ ] CCC Digital Key 릴리스 버전(예: R3) 및 채널(BLE/UWB/NFC) 범위
- [ ] 디지털키 PKI 모델(CCC 정의) — 코어 PKI와 분리 구조
- [ ] FMS 발급 절차 (사용자 인증 → 키 발급 → 권한 위임)
- [ ] 디지털키↔모바일앱 보안 통신 암호 스위트 — **Ed25519/X25519 등 확인 필요**
- [ ] 키 생애주기(발급·공유·폐기·감사)와 CRA·CCC 적합성
- [ ] Tier-B에 CCC 개요 참조(REF) 추가 여부
