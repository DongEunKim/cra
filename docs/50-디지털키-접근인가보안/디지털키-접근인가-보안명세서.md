# 차세대 건설기계 디지털키 접근·인가 보안 명세서

| 항목 | 내용 |
|------|------|
| **문서 ID** | DOC-50 (A5 · 디지털키 접근·인가 보안) |
| **문서 버전** | v0.1 (스켈레톤 — 자리 예약, 착수 예정) |
| **문서 분류** | 보안 아키텍처 / 기술 명세서 |
| **적용 대상** | 디지털키(CCC), 디지털키 시스템(발급 백엔드), TGU 내 BLE MCU, FMS 앱(디지털키 통합) |
| **지배 표준** | CCC(Car Connectivity Consortium) Digital Key |
| **용어 기준** | [DOC-00 용어집](../00-공통/용어집.md) |

본 문서는 장비의 물리 접근·조작 인가를 위한 **CCC 기반 디지털키** 보안을 규정한다. 현재 디지털키 시스템이
CRA에 부합하지 않아 CCC 적용 디지털키로 전환한다. 이 도메인은 **코어 PKI(FOTA·진단·클라우드, [DOC-10](../10-시스템장비-보안아키텍처/시스템장비-보안아키텍처명세서.md))와 분리된
별도 신뢰 도메인**이며, CCC가 정의하는 자체 암호 스위트를 사용한다.

> 🔴 **스켈레톤 문서.** 아래 목차와 미결은 착수 시 채운다. 코어(DOC-10~40) 안정화 후 진행.

---

## 목차(안)

| 절 | 제목 | 내용 |
|----|------|------|
| 1 | 범위·표준 | CCC Digital Key 릴리스·채널(BLE/UWB/NFC) 범위, CRA 부합 목표 |
| 2 | 신뢰 도메인·PKI | CCC PKI 모델 — 코어 PKI(DOC-10)와의 분리·경계 |
| 3 | 액터·구성 | 디지털키 시스템(실제 발급 백엔드), FMS 앱(디지털키 통합·사용자 클라이언트), TGU 내 BLE MCU(장비 엔드포인트) |
| 4 | 디지털키 발급 절차 | 사용자 인증 → (디지털키 시스템이) 장비 디지털키 발급 → 권한 위임. FMS 앱은 프론트엔드 |
| 5 | 디지털키↔모바일앱 보안 통신 | 세션 수립·암호 스위트(**Ed25519/X25519 등 — 확인 필요**) |
| 6 | 생애주기 | 발급·공유·해지·감사, 부품 교체 시 처리 |
| 7 | 적합성 | CCC 적합성 및 CRA 매핑(→ REF-03) |

## 아키텍처 반영 필요 (착수 시)
- DOC-10 §2 시스템 다이어그램에 디지털키 시스템·FMS 앱·BLE 도메인 추가
- TGU 역할에 'BLE 디지털키 엔드포인트' 반영(현재 인스톨러+텔레매틱스)
