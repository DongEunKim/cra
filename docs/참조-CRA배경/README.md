## Tier A(사양)와의 관계

- Tier B는 **요구·프로세스·증명**을 다루고, Tier A는 그것을 만족하는 **아키텍처·메커니즘**을 규정한다.
- 두 계층의 연결 고리는 각 절차 사양의 **"보안 속성(무엇을 보증하는가)"** 항목이다. REF-03이 이 고리들을
  모아 CRA 요구에 매핑한다.

> ⚠️ 법률·인증 판단이 필요한 서술은 컨설턴트/법무 검토를 거친다. 본 계층 문서는 그 전제의 기술 배경이다.
