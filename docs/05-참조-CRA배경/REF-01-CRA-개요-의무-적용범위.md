# CRA 개요 · 의무 · 적용범위 (레퍼런스)

| 항목 | 내용 |
|------|------|
| **문서 ID** | REF-01 (Tier B · 레퍼런스) |
| **상태** | 🔴 레퍼런스 스텁 |
| **소관** | CRA 컨설턴트 (본 문서는 사양설계자 인지용 요약) |
| **용어 기준** | [DOC-00 용어집](../00-공통/용어집.md) |

> 본 문서는 EU 사이버 복원력 법안(Cyber Resilience Act, **Regulation (EU) 2024/2847**)을 사양설계자가
> 이해하기 위한 **배경 요약**이다. 조문의 정확한 해석·적용 판단은 컨설턴트·법무 검토를 따른다.

---

## 1. CRA란 (설계자 관점)

디지털 요소를 가진 제품(products with digital elements)의 **사이버 보안**을 시장 출시 조건으로 요구하는
EU 규정. 핵심은 "안전하게 설계하고(secure by design), **지원 기간 내 보안을 유지**하라"이다.
→ 이 프로젝트의 FOTA·PKI·진단 사양이 그 '유지' 수단을 제공한다.

## 2. 설계에 영향을 주는 핵심 의무 (요지)

> 정확한 조문·부속서 번호는 REF-03 매핑에서 컨설턴트 확인 후 확정. 여기서는 설계 함의만 요약.

| 의무 영역 | 설계 함의 | 대응 사양(Tier A) |
|-----------|-----------|-------------------|
| 안전한 기본 설계 | 무단 접근 차단, 최소 권한 | PKI·인증, UDS 0x29 Role |
| 무결성·정품성 | 변조·위조 펌웨어 차단 | 전자서명, Secure Boot |
| 기밀성 | IP·데이터 보호 | Secure Flash(암호화) |
| **보안 업데이트 제공** | 지원 기간 내 적시 업데이트 | FOTA·유선 업데이트 |
| 취약점 처리 | 알려진 취약점 제거·다운그레이드 차단 | Anti-Rollback, 폐기 전략 |
| SBOM·추적성 | 구성요소 목록·이력 관리 | VLM·부품 이력 |
| 취약점 공개·사고 신고 | CVD·ENISA 통지 **프로세스** | REF-02 관리체계 |

## 3. 적용범위 · 제품 분류 (확인 필요)

- 건설기계 제품군이 CRA 적용 대상·**제품 분류(중요도 등급)** 중 어디에 속하는지 **컨설턴트 확정 필요**.
- 지원 기간(support period) 정의, 적합성 평가(conformity assessment) 경로도 컨설턴트 소관.
