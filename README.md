# CRA 대응 보안 기술문서 프로젝트

건설기계 제어기의 **소프트웨어 업데이트(FOTA)** 및 **PKI·진단(UDS 0x29) 보안 아키텍처**를
사내외 배포용 공식 기술문서로 정제하고, **EU 사이버 복원력 법안(Cyber Resilience Act, CRA)** 요구사항에
대응하기 위한 문서 관리 프로젝트이다.

## 문서 원본 방침 (Docs-as-Code)

- **원본(Source of Truth):** Markdown (`docs/`)
- **다이어그램/자산:** `assets/`
- **버전관리:** git — 모든 변경은 커밋 이력으로 추적한다(CRA 추적성 요건 부합).
- **언어:** 한국어

> 배포용 HTML/PDF는 Markdown 원본으로부터 생성한다. (빌드 파이프라인은 추후 구성)

## 디렉토리 구조

```
CRA/
├── README.md                  # (이 문서) 프로젝트 개요
├── CLAUDE.md                  # 작업 가이드 / 문서 규약
├── docs/                      # ★ 공식 문서 원본 (Markdown)
│   ├── README.md              #   문서 체계 인덱스
│   ├── 00-공통/               #   용어집·약어·참조표준
│   ├── 10-FOTA보안아키텍처/   #   FOTA 보안 명세서 (legacy v5.1 + v5.2 통합)
│   ├── 20-PKI-UDS진단보안/    #   PKI & UDS 0x29 진단 보안 명세서 (legacy v1.2)
│   └── 30-CRA대응/            #   CRA 요구사항 ↔ 아키텍처 매핑 (신규)
├── assets/
│   └── diagrams/              #   SVG 등 다이어그램 자산
└── legacy/                    # 원본 HTML 3종 (보존, 편집 금지)
    ├── fota_v5.1.html
    ├── fota_v5.2.html
    └── pki_v1.2.html
```
